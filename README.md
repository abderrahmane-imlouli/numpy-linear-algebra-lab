# NumPy Linear Algebra Lab

## Overview

This project demonstrates core NumPy operations and fundamental linear algebra concepts commonly used in scientific computing and engineering.

The project covers array creation, reshaping, indexing, normalization, matrix analysis, and linear algebra operations.

## Features

* Create one-dimensional and multi-dimensional arrays
* Matrix reshaping
* Array slicing and indexing
* Boolean masking
* Statistical calculations
* Data normalization
* Matrix transpose
* Determinant calculation
* Matrix inversion

## Technologies

* Python
* NumPy

## Learning Objectives

This project was created to practice:

* Scientific computing with NumPy
* Matrix manipulation
* Data preprocessing
* Linear algebra fundamentals

## Topics Covered

* Arrays
* Matrices
* Reshaping
* Indexing
* Statistics
* Normalization
* Determinants
* Inverse Matrices
